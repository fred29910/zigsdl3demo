# 游戏大厅界面 · UI/UX 设计方案

**Feature**: `001-game-lobby-ui`  
**状态**: 设计基线，供 `plan.md`、`data-model.md`、`contracts/`、`quickstart.md` 引用  
**范围**: 大厅主界面、外部模型预览界面、启动/失败/返回状态；不改变四个运行模式内部的玩法、HUD 与操作（Esc 语义除外）  
**技术前提**: 桌面 SDL3 + SDL GPU + Dear ImGui，单窗口，Zig 主语言；所有界面文本中文；窗口可缩放；验收基线为 Linux 虚拟显示 + Mesa Lavapipe

---

## 0. 设计目标与不变量

**目标**

1. 启动后第一眼看到大厅；进入默认训练场只需 1 次选择，从启动到可操作 < 3 秒。
2. 四个模式在同一屏内可辨认、可进入；外部模型路径只存在于专门预览界面。
3. 任何失败都停留在大厅，给出可读中文原因，并可重试或改选。
4. 窗口从 640×480 到 2560×1440 均无控件重叠、无关键入口被裁切。
5. 视觉上像“训练场控制台”，而不是 ImGui 调试面板。

**设计不变量（plan / contracts 必须保持）**

- 大厅恒有 4 个模式入口：1 个主入口「开始训练」+ 3 个次级入口；主入口在 800×600 下无需滚动即可见。
- 「退出」始终位于固定页脚，不进入滚动区域；Esc 永不退出程序。
- 任一时刻最多一个“待启动”转换；转换期间所有入口锁定。
- 设置范围与默认值固定：灵敏度 0.50–2.00、步长 0.05、默认 1.00；音量 0–100、步长 1、默认 100；不持久化。
- 外部模型路径不写入磁盘、不在大厅主界面回显；离开预览界面即清空草稿。
- 所有界面文案取自第 5 节文案表，不允许散落硬编码的近义文本。

**非目标**

- 不做账号、联网、匹配、多人房间。
- 不做设置持久化、配置导入导出、主题切换。
- 不改变模式内部 HUD、武器、物理、机器人行为。
- 不使用系统原生消息框；错误一律在窗口内呈现。

## 1. 视觉方向

**概念：训练场控制台（Range Console）**

深色石墨底 + 一条暖琥珀主色，像室内靶场的射灯与地面标线。背景用极低透明度的透视网格暗示训练场地面，主入口后方有一团琥珀色柔光，形成唯一焦点。整体克制、精确、没有装饰性插画，靠层级、留白和一条主色建立识别度。

### 1.1 设计令牌

**颜色**

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `bg.base` | `#0B0E13` | 窗口底色 |
| `bg.gradient` | `#0B0E13 → #121823` | 纵向渐变 |
| `surface.panel` | 白色 4.5% 叠加 | 面板、设置区 |
| `surface.card` | 白色 3.5% 叠加 | 次级模式卡 |
| `surface.hover` | 白色 7.5% 叠加 | 卡片悬停 |
| `border.default` | `#2B3442` | 面板/卡片描边 |
| `border.hover` | `#46566B` | 悬停描边 |
| `text.primary` | `#E9EDF4` | 标题、模式名、数值 |
| `text.secondary` | `#A3AEBD` | 说明、副标题 |
| `text.muted` | `#7E8A9A` | 范围提示、页脚提示 |
| `accent.primary` | `#F0A83C` | 主按钮、焦点强调、左侧标线 |
| `accent.hover` | `#FFC163` | 主按钮悬停 |
| `accent.pressed` | `#D68F2B` | 主按钮按下 |
| `accent.ink` | `#1B1204` | 主按钮上的深色文字 |
| `focus.ring` | `#8FD3E8` | 键盘焦点环（2px） |
| `error.fg` | `#F07A72` | 错误文字/描边 |
| `error.bg` | 错误色 10% 叠加 | 错误横幅底 |
| `warning.fg` | `#E7C15C` | 警告文字 |
| `warning.bg` | 警告色 10% 叠加 | 警告横幅底 |
| `scrim` | `#06080C` 66% | 启动/返回遮罩 |
| `disabled` | 整体不透明度 45% | 锁定态 |

对比度要求：正文与说明文字对底色 ≥ 4.5:1；主按钮深色字对琥珀底 ≥ 7:1；焦点环对任意底色可见。错误/警告不得只靠颜色区分，必须带「错误」「提示」文字标签。

**字体**

| 层级 | 字号/行高（逻辑点，scale 1.0） | 字重 | 用途 |
| --- | --- | --- | --- |
| 展示 | 34 / 44（宽屏）；28 / 38（中/窄屏） | Bold | 大厅标题 |
| 标题 | 20 / 28 | Bold | 模式名、面板标题 |
| 正文 | 16 / 24 | Regular | 说明、按钮、输入 |
| 说明 | 13 / 18 | Regular | 范围提示、页脚、错误详情 |

- 字体族：内嵌 Noto Sans SC（或同许可的思源黑体）Regular + Bold 子集；不依赖系统字体作为正常路径。
- 中文不做斜体、不做全大写；数字使用等宽数字（若字体支持），数值字段右对齐并固定宽度，避免跳动。
- 单行中文控制在约 34 个汉字以内；长说明自动换行，不截断关键原因。

**间距、圆角与尺寸**

| 项 | 宽屏 ≥1080 | 中屏 720–1079 | 窄屏 <720 |
| --- | --- | --- | --- |
| 页面左右留白 | 48 | 28 | 20 |
| 内容最大宽度 | 1120 | 760 | 100% |
| 页头高度 | 56 | 48 | 44 |
| 页脚高度 | 52 | 48 | 44 |
| 主入口高度 | 96 | 76 | 72 |
| 次级卡片高度 | 72 | 64 | 60 |
| 设置行高 | 44 | 44 | 44 |
| 区块间距 | 32 | 20 | 16 |
| 卡片间距 | 12 | 10 | 8 |

- 基础间距单位 4；常用值 8 / 12 / 16 / 24 / 32 / 48。
- 圆角：面板 12、卡片 10、按钮/输入框 8、主入口 12；描边统一 1px。
- 可点击区域最小 44×44 逻辑点；主入口整卡可点，不只点文字。
- 阴影只用于启动浮层，使用低透明度大范围柔影；常规面板靠描边分层，避免 Lavapipe 上的高开销模糊。

**背景与质感**

- 纵向渐变 + 底部淡出暗角（不透明度 ≤ 20%）。
- 透视网格：约 16–24 条 1px 线，白色 3%–4%，静态，不参与动画。
- 主入口后方琥珀径向柔光，不透明度 6%–8%，半径约主入口宽度 1.2 倍。
- 全部用 ImGui 绘制列表绘制，不引入背景贴图；不使用实时模糊、噪点贴图或大面积阴影。

**动效**

- 入场：页头、主入口、模式区依次 180ms 淡入，间隔 24ms；输入在首帧即生效，动画不阻塞点击，不延迟进入。
- 启动浮层：150ms 淡入；错误横幅：120ms 淡入 + 4px 上移；返回大厅：160ms 淡入。
- 加载指示：900ms/圈线性旋转。
- 悬停/按下：颜色即时切换，按下内容下移 1px；不做缓动补间，避免即时模式下的状态复杂度。
- 除加载指示外无循环动画；不做布局尺寸动画，避免文字重新栅格化造成抖动。

**窄屏 <720：单栏纵向、内容可滚动、页脚固定**

- 顺序：页头 → 主入口 → 运行模式（三张卡纵向堆叠）→ 设置（两项纵向堆叠）→ 页脚。
- 页头与页脚固定；中间内容区域独立滚动；滚动条默认低调，仅悬停加深。
- 退出按钮始终在页脚，不随内容滚走；错误横幅出现在模式区上方，宽度撑满内容区。

### 2.2 视觉层级与焦点

1. **第一焦点**：主入口「开始训练」。唯一大面积琥珀填充、唯一带柔光的元素，位于宽屏左栏上部/中窄屏首屏上半部。
2. **第二层**：大厅标题与四个模式名。标题大而低饱和，模式名清晰但使用描边卡片，不与主入口争色。
3. **第三层**：模式说明、设置标签与数值。
4. **第四层**：范围提示、页脚 Esc 提示。
5. **最低层**：「退出」按钮。位置独立、描边幽灵样式，悬停才转为错误色，避免误触。

主入口卡片内部结构：左上小标签「默认训练场」（13px，`text.muted`）→ 主标题「开始训练」（20–24px Bold，`text.primary`）→ 右侧手绘折线箭头（绘制列表，不依赖字体字形）→ 卡片左侧 3px 琥珀竖线。悬停时描边变亮、竖线延长至卡片高度。

### 2.3 缩放与重排策略

- **布局单位是逻辑点**：窗口像素尺寸 ÷ 显示缩放（DPI）。DPI 只影响文字栅格化与像素密度，不改变断点。
- **断点**：宽屏 ≥1080；中屏 720–1079；窄屏 <720。断点变化时整块重排，不做动画。
- **文字不随窗口缩小而缩小**：只按 DPI 放大；空间不足时换行、堆叠或滚动，保证 13px 说明仍可读。
- **字体栅格化分档**：按 0.25 的 DPI 档位预生成（如 1.0 / 1.25 / 1.5 / 1.75 / 2.0），仅在档位变化时重建字体图集；禁止每帧重建或无限放大位图。
- **实时重排**：每帧按当前窗口尺寸计算；最小化到 0 尺寸时跳过绘制，恢复后立即重排。控件不使用绝对像素坐标记忆。
- **滚动兜底**：内容高于可用区域时，中间区域滚动；页头/页脚固定。滚动不改变焦点顺序。
- **过小窗口**：宽度 <520 或高度 <400 时，内容区顶部显示常驻提示「窗口过小，请放大窗口以完整显示大厅。」；退出仍可用。建议实现时把窗口最小尺寸限制为 640×480，但设计不依赖该限制。
- **800×600 目标**：中屏布局在 800×600 下应首屏完整显示主入口、3 个次级入口、2 项设置和页脚，无需滚动。

## 3. 各状态呈现

### 3.1 状态总表

| 状态 | 触发 | 主区域表现 | 控件可用性 | 焦点 |
| --- | --- | --- | --- | --- |
| 默认态 | 启动完成 / 从模式返回 | 双栏或单栏大厅，无横幅 | 全部可用 | 主入口（首次）；上次退出模式（返回后） |
| 启动中 | 确认任一模式 | 内容区遮罩 + 居中状态卡；页脚保持可见 | 模式入口、重试锁定；退出可用（取消并退出） | 无（等待） |
| 启动失败 | 初始化返回错误 | 遮罩消失，模式区上方错误横幅 | 全部恢复；「重试」「关闭提示」可用 | 「重试」 |
| 音频缺失 | 进入场景前检测到无输出设备 | 模式区上方黄色警告横幅 | 全部可用，不阻断 | 保持原焦点 |
| 设置非法 | 数值提交时为空/非数字/越界 | 对应设置行下方提示行变警告色 | 设置与模式入口均可用 | 保持在该数值输入框 |
| 预览编辑 | 点击「外部模型预览」 | 大厅主体替换为预览面板 | 路径输入、加载、返回可用 | 路径输入框 |
| 预览加载中 | 确认合法路径 | 预览面板内状态行 + 输入/按钮禁用 | Esc 忽略；关闭窗口可退出 | 无 |
| 预览错误 | 空路径/格式/不存在/加载失败 | 输入框下方内联错误块 | 输入与按钮恢复；路径保留 | 路径输入框（文本全选） |
| 返回中 | 模式内按 Esc，释放资源超过 150ms | 内容区遮罩 + 「正在返回大厅…」 | 全部锁定 | 无 |
| 字体降级 | 内嵌与系统 CJK 字体均不可用 | 仅 ASCII 可读提示 + 退出 | 仅退出可用 | 退出 |

### 3.2 默认态

- 页头标题「训练场大厅」，副标题一行；宽屏页头右侧留空，不堆叠信息。
- 主入口默认获得键盘焦点，焦点环可见；鼠标悬停时同样有明确反馈。
- 设置显示当前值：灵敏度固定两位小数（`1.00`），音量整数（`100`）；下方常驻范围提示行。
- 页脚左侧「大厅内按 Esc 不会退出」，右侧「退出」。
- 首次进入有 180ms 淡入；动画期间点击立即生效，不等待动画结束。

### 3.3 模式启动中 / 失败

**启动中**

- 点击/确认后立即锁定所有模式入口（不透明度 45%，无悬停反馈），并在同一帧记录唯一待启动模式。
- 若初始化超过 150ms，显示内容区遮罩（页头/页脚不被遮住）+ 居中状态卡：旋转指示 + 「正在进入{模式名}…」+ 次级说明「首次进入可能需要几秒」。
- 页脚「退出」仍可点击：视为取消本次启动并退出程序；关闭窗口始终可退出。
- 不显示进度百分比，不显示技术日志；避免虚假进度。

**失败**

- 遮罩消失，错误横幅出现在模式区上方（窄屏为内容顶部），不覆盖主入口。
- 横幅结构：`错误` 文字标签 → 标题「无法启动{模式名}」→ 可读原因 → 操作「重试」「关闭提示」。
- 原因映射：图形设备失败用专门文案并指向「Vulkan 清屏演示」排查；其余用通用文案；原始技术错误只作为说明行附加，不单独作为唯一信息。
- 其他模式入口保持可用；选择其他模式时自动关闭旧横幅。重试沿用同一模式并重新进入启动中。
- 焦点移到「重试」；「关闭提示」只关闭横幅，不改变其他状态。
- 音频缺失不进入失败态，改为黄色警告横幅「未检测到音频输出设备，将以静音运行。」+「知道了」，不阻断任何入口。

### 3.4 设置非法输入态

每项设置由三部分组成：标签 + 当前值（可编辑）+ 滑杆；下方固定一行提示（默认显示允许范围，非法时替换为警告文案），高度预留，避免布局跳动。

- 滑杆始终在合法范围，拖动即生效，灵敏度按 0.05 吸附，音量按 1 吸附。
- 数值框获得焦点时全选；输入过程允许临时非法字符，不即时打断。
- 提交时机：Enter、失焦、点击步进、或激活任一模式前统一提交。
- 越界：立即收敛到最近边界并回写字段，提示行显示「已调整为 …（允许范围 …）」；字段描边保持错误色，直到下一次成功提交。
- 空值/非数字：恢复上一次有效值，提示「请输入数字（允许范围 …）」；不写入任何非法值。
- 提示不会自动消失，直到用户再次编辑或离开该设置行，保证可读完。
- 非法输入不阻断模式进入；激活模式前先提交并收敛，保证进入场景的值一定合法。

### 3.5 外部模型预览界面

- 从大厅主界面进入，**同一窗口内替换主体内容**，不新开窗口；页头保留大厅标题，页脚 Esc 提示改为「按 Esc 返回大厅」，「退出」仍在。
- 面板居中，最大宽度 720（窄屏撑满并留 20 边距）；标题「外部模型预览」，说明一行。
- 路径输入：单行、全宽、支持粘贴；获得焦点即全选；Enter 等同「加载模型」；Esc 直接返回大厅主界面并清空草稿。
- 输入下方常驻提示：「支持 .glb 与 .gltf；相对路径以程序运行目录为基准，可直接粘贴路径。」
- 按钮：主按钮「加载模型」；次按钮「返回大厅」。两者均整块可点。
- 校验顺序：空 → 扩展名 → 文件存在 → 加载。每类错误在输入框下方内联显示，路径保留、输入框获得焦点，用户可直接修改重试。
- 加载中：输入框与两个按钮禁用，状态行显示旋转指示 +「正在加载模型…」；Esc 忽略，关闭窗口可退出；不显示旧错误。
- 加载成功：进入现有自由飞行查看模式；预览草稿清空。之后按 Esc 返回大厅主界面，而不是回到预览界面。
- 加载失败：保留路径，显示「模型加载失败：{可读原因}」及「请检查模型文件及其引用的 .bin 与纹理是否完整。」；可修改后重试或返回。
- 离开预览界面（返回、成功、Esc）即清空路径，重新进入时为空，避免旧路径与旧错误残留。

### 3.6 返回大厅与再次进入

- 任一运行模式内按 Esc：先释放该模式资源，再显示大厅；若释放超过 150ms，显示遮罩与「正在返回大厅…」。
- 返回后：设置值保留；错误/警告横幅清空；所有模式入口恢复可用；预览路径清空；焦点回到**刚才退出的模式**（训练场对应主入口，其余对应各自卡片）。
- 不显示“已退出”提示或成功提示，避免噪音；用 160ms 淡入表示状态切换。
- 再次进入同一模式按全新会话处理：无禁用残留、无旧回合数据、无旧错误；界面上不提供“继续上一局”的暗示。
- 从训练场返回后，鼠标必须已释放、光标可见、按键状态清空；大厅不使用相对鼠标模式。

## 4. 交互流程

### 4.1 鼠标

- 整卡/整按钮可点；按下时内容下移 1px，松开且在控件内才触发。
- 悬停：卡片描边变亮、表面提亮、左侧琥珀标线出现；主按钮提亮；退出按钮转为错误色描边与文字。
- 禁用：不透明度 45%，无悬停/按下反馈，点击无效果。
- 大厅始终使用绝对鼠标、光标可见；从任何模式返回前先释放鼠标捕获。
- 不使用右键菜单、滚轮切换模式等隐藏交互。

### 4.2 键盘与焦点顺序

- 初始焦点：主入口「开始训练」。
- Tab 顺序：主入口 → 外部模型预览 → 2D 输入演示 → Vulkan 清屏演示 → 视角灵敏度 → 音量 → 退出 → 回到主入口。
- 模式组内可用 ↑/↓ 在四个模式间移动；Enter / Space 激活；数值框内 ↑/↓ 调整步长，不切换焦点。
- 预览界面顺序：路径输入 → 加载模型 → 返回大厅 → 退出 → 路径输入。
- 焦点环：2px `focus.ring`，外扩 1px；任何焦点位置都必须可见，不能只靠文字颜色。
- 键盘导航不得捕获 Esc 作为退出；Esc 规则见 4.3。
- 若某控件在 ImGui 键盘导航下表现不稳定，鼠标路径必须始终完整可用；键盘为增强，不是唯一路径。

### 4.3 Esc 行为矩阵

| 场景 | Esc 行为 |
| --- | --- |
| 大厅主界面，无横幅、无编辑 | 无操作，停留大厅 |
| 大厅主界面，有错误/警告横幅 | 关闭横幅，停留大厅 |
| 设置数值框编辑中 | 撤销本次编辑，恢复上次有效值；不退出 |
| 外部模型预览（编辑/错误） | 返回大厅主界面，清空路径草稿与错误 |
| 外部模型预览加载中 | 忽略；窗口关闭仍可退出 |
| 任一运行模式 | 返回大厅并释放资源 |
| 启动中遮罩 | 忽略；使用「退出」或关闭窗口退出 |
| 字体降级界面 | 无操作；只能点「Exit」或关闭窗口 |

**总规则：Esc 永不退出程序。** 退出只有两条路径：大厅页脚「退出」按钮、关闭窗口。

### 4.4 退出

- 「退出」位于页脚右端，与模式卡保持至少一个区块间距；幽灵描边，悬停转错误色，tooltip「退出程序」。
- 单击即退出，不做二次确认（本版本为单机会话 Demo，确认框会增加无谓摩擦）。
- 启动中点击退出：取消待启动操作并退出；不留下半初始化窗口。
- 连续点击只处理第一次；进入“正在退出”后忽略后续输入。
- 关闭窗口在任何状态都立即生效，包括加载中。

### 4.5 防抖与单次确认

- **单次确认锁**：规格 Edge Cases 要求“只进入最后确认的一个模式”，因此在初始化实际开始前，待启动模式以**最后一次确认**为准（同一批快速输入中后确认者覆盖先确认者）；初始化一旦开始即锁定所有入口，后续输入忽略、不排队，最终只产生一次初始化。
- **输入边沿**：激活只认按键按下边沿，忽略系统按键重复；长按 Enter 不会重复启动。
- **冷却窗口**：每次转换结束（成功进入、失败返回、返回大厅）后 250ms 内忽略新的模式激活，吸收队列中的重复点击；冷却期间不显示禁用态，仅静默忽略。
- **单帧单动作**：每帧最多处理一个模式激活/加载/退出请求。
- **预览加载**：与模式启动共用同一把锁；加载中再次点击「加载模型」无效。
- **重试**：与首次启动共用锁与冷却，不允许并发重试。
- **不排队**：失败后不会自动执行冷却期间点击过的其他模式，用户需重新选择。

## 7. 风险与设计决策

### R1. ImGui 中文字体缺失（最高风险）

**风险**：ImGui 默认字体不含 CJK 字形；当前工程也未加载自定义字体。直接使用默认字体会让所有中文变成方块或空白，直接违反 FR-009。

**设计决策（按优先级）**

1. **正常路径只认内嵌字体**：随程序打包 Noto Sans SC（OFL）Regular + Bold 子集，嵌入可执行文件，运行时不依赖系统字体。子集必须覆盖：第 5 节全部文案、ASCII、CJK 标点（「」、：、；、，、。、…、·、–）以及 GB2312 常用汉字，保证用户粘贴中文路径时大多可显示。字体许可与来源写入 README/第三方声明。
2. **外部同目录兜底**：若嵌入资源因打包缺陷缺失，尝试可执行文件同目录的 `assets/fonts/` 同名字体文件；不引入 fontconfig 等新依赖。
3. **系统字体兜底（尽力而为）**：按已知路径尝试 Noto Sans CJK SC、Source Han Sans SC、WenQuanYi Zen Hei；失败不阻塞，进入第 4 步。
4. **可读降级界面**：以上都失败时，使用 ImGui 内置 ASCII 字体显示三行英文提示（见 5.5）和一个「Exit」按钮，并写中文日志。**宁可显示可读英文，也不显示豆腐块或空白**。该界面是打包缺陷态，正常验收必须不出现；FR-009 的中文要求适用于正常路径，此例外需在 plan 中记录。
5. **字形自检**：启动时对固定文案字符集做覆盖检查；缺字则按第 2–4 步降级，并在日志中列出缺失字符。验收时逐屏截图确认无缺字。
6. **字号与缩放**：按 DPI 档位分别栅格化，禁止把 1.0 字号位图放大到 1.5 使用；档位变化才重建图集，避免每帧重建导致卡顿。
7. **用户路径的已知边界**：路径输入可能包含子集外的生僻字或 emoji，允许显示为占位符；这属于用户输入，不是界面文案，验收以“界面文案完整”为准。提示用户可直接粘贴路径，减少 IME 输入。

### R2. ImGui 默认外观像调试工具

- 决策：统一使用 1.1 的令牌；大厅使用全屏无标题栏宿主窗口，背景由绘制列表完成；所有面板去掉 ImGui 默认标题栏、滚动条样式与间距，改用自定义卡片绘制。禁止在各屏散落魔法颜色。

### R3. 中文路径与输入法

- 决策：以“粘贴”为主要输入方式，并在提示中明说；单行输入框横向滚动，不折行；不依赖 IME 组合事件完成校验。路径中的中文由字体子集覆盖常用字；生僻字降级为占位符，不作为验收失败。

### R4. Esc 与文本编辑冲突

- 决策：按 4.3 的优先级执行；Esc 在数值框内只撤销编辑，在预览界面直接返回大厅，在大厅主界面只关横幅/无操作。实现时先消费文本编辑态，再处理界面返回，最后才是空操作。

### R5. 小窗口与缩放

- 决策：断点重排 + 滚动兜底 + 固定页脚；文字不缩小；建议窗口最小 640×480。低于 520×400 显示常驻提示，退出仍可用。禁止用整体 UI 缩放把 800×600 压成不可读的小字。

### R6. 错误信息可读性

- 决策：所有错误先给中文人话结论，再给操作建议；技术原文只作为附加详情，且自动换行。横幅高度随内容增长，窄屏可滚动；关键原因不截断。错误与警告必须带文字标签，避免只靠颜色。

### R7. 快速输入导致多次初始化

- 决策：单次确认锁 + 按键边沿 + 250ms 冷却 + 每帧单动作；不排队后续点击。视觉上第一帧就禁用入口，让用户明确“已受理”。

### R8. Lavapipe 软件渲染开销

- 决策：背景只用一个渐变 + 少量直线 + 一个径向柔光；不做实时模糊、噪点贴图、大面积阴影；动画只改透明度；字体图集按档缓存。大厅静态时绘制调用保持低位，确保 800×600 下仍能快速进入训练场。

### R9. 鼠标捕获与焦点残留

- 决策：大厅永远绝对鼠标、光标可见；从模式返回前释放捕获并清空按键状态；启动/返回遮罩期间不接收场景输入。避免“回到大厅但鼠标仍被锁住”的严重可用性问题。

### R10. 误触退出

- 决策：退出放在页脚右端，与模式卡至少隔一个区块；幽灵样式，悬停才转错误色；不加确认框，但保证位置与样式不吸引误点。关闭窗口仍是第二退出路径。

## 8. 给 plan / data-model / contracts 的引用要点

### 8.1 建议的界面状态（供 data-model）

- `screen`：`lobby_main` | `lobby_external_preview` | `mode_training` | `mode_external_viewer` | `mode_demo_2d` | `mode_clear`
- `lobby_status`：`idle` | `launching(mode)` | `failed(mode, cause)` | `warning_audio`
- `settings`：`sensitivity`（0.50–2.00，步长 0.05，默认 1.00）、`volume`（0–100，步长 1，默认 100）、每项“上次有效值/编辑中/提示态”
- `preview`：`path_draft`、`phase`（`editing` | `loading` | `error`）、`error_kind`（`empty` | `format` | `not_found` | `load`）
- `focus`：当前焦点控件；`last_mode`：返回后焦点目标
- `transition_pending`：单次确认锁；`cooldown_until`：250ms 冷却

### 8.2 状态转换（供 contracts）

| 从 | 事件 | 守卫 | 到 | 副作用 |
| --- | --- | --- | --- | --- |
| lobby_main/idle | 确认模式 | 无 pending、无冷却 | lobby_main/launching(mode) | 立即锁定入口，记录唯一模式 |
| launching | 初始化成功 | — | 对应 mode | 隐藏大厅，保留设置 |
| launching | 初始化失败 | — | lobby_main/failed | 显示横幅，焦点到重试 |
| failed | 重试 | 无 pending | launching(同模式) | 关闭旧横幅 |
| failed | 选择其他模式 | 无 pending | launching(新模式) | 关闭旧横幅 |
| lobby_main | 选择外部模型预览 | 无 pending | lobby_external_preview | 清空路径与错误 |
| preview/editing | 确认 | 路径为空 | preview/error(empty) | 聚焦输入框 |
| preview/editing | 确认 | 格式不支持 | preview/error(format) | 聚焦输入框 |
| preview/editing | 确认 | 文件不存在 | preview/error(not_found) | 聚焦输入框 |
| preview/editing | 确认 | 合法 | preview/loading | 禁用输入与按钮 |
| preview/loading | 加载成功 | — | mode_external_viewer | 清空草稿 |
| preview/loading | 加载失败 | — | preview/error(load) | 保留路径，恢复输入 |
| 任一 mode | Esc | — | lobby_main/idle | 释放资源、清空横幅、焦点回上次模式 |
| preview | Esc | 非加载中 | lobby_main/idle | 清空草稿 |
| lobby_main | 退出/关闭窗口 | — | 退出 | 取消 pending，清理资源 |
| launching | 退出/关闭窗口 | — | 退出 | 中止初始化，不留半窗口 |

### 8.3 校验规则（供 contracts）

- 灵敏度：提交时解析为数字；空/非数字 → 恢复上次有效值；<0.50 → 0.50；>2.00 → 2.00；吸附到 0.05；显示两位小数。
- 音量：提交时解析为数字；空/非数字 → 恢复上次有效值；<0 → 0；>100 → 100；取整；显示整数。
- 激活任一模式前先提交两项设置，确保进入场景的值合法。
- 预览路径：去首尾空白；空 → 错误；扩展名非 `.glb`/`.gltf`（大小写不敏感）→ 错误；文件不存在 → 错误；通过后进入加载。
- 所有错误提示与按钮文案必须来自第 5 节键值，不得新增近义文案。
