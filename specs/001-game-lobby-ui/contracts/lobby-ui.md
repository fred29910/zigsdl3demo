# Contract: 大厅界面（用户可见契约）

本契约约束大厅的可见控件、中文文案、状态呈现与交互反馈。实体字段见 [data-model.md](../data-model.md)，验证场景见 [quickstart.md](../quickstart.md)，完整 UI 设计与 D-01–D-18 验收点见 [ui-design.md](../ui-design.md)。

## 控件与中文文案（FR-009）

精确文案以 `ui-design.md` 第 4 节为准；以下为必须一致的核心文本：

| 位置 | 精确文案 |
| --- | --- |
| 页头标题 / 副标题 | 训练场大厅 / 选择运行模式，或先调整本次会话设置 |
| 主入口 | 默认训练场 / 开始训练 / 一键进入内嵌训练场 / 进入后按 Tab 开始 |
| 模式区标题 | 运行模式 |
| 次级模式 | 外部模型预览；选择本地 .glb 或 .gltf 文件查看 / 2D 输入演示；检查窗口事件、方向键与鼠标增量 / Vulkan 清屏演示；检查图形设备与交换链 |
| 设置区 | 本次会话设置 / 视角灵敏度（允许范围 0.50–2.00）/ 音量（允许范围 0–100）/ 设置仅在本次运行内有效，重启后恢复默认 |
| 非法设置 | 请输入数字（允许范围 …）；已调整为 0.50 / 2.00 / 0 / 100（按越界方向） |
| 页脚 | 大厅内按 Esc 不会退出 / 退出 |
| 模型路径问题 | 请输入模型文件路径。/ 找不到文件，请检查路径是否正确。/ 暂不支持该格式，请选择 .glb 或 .gltf 文件。/ 请检查模型文件及其引用的 .bin 与纹理是否完整。 |
| 启动/加载/失败 | 正在进入{模式名}… / 正在加载模型… / 错误 / 无法启动{模式名} / 初始化失败，请重试或选择其他模式。/ 重试 / 关闭提示 |
| 音频缺失 | 提示 / 未检测到音频输出设备，将以静音运行。/ 知道了 |

文案规则：叙述全部中文；`Vulkan`、`2D`、`.glb`、`.gltf`、`Tab`、`Esc` 保留原文；标点全角、省略号用「…」。

## 状态呈现契约

| 状态 | 必达呈现 |
| --- | --- |
| 默认态 | 中文大厅可见、控件可交互；主入口默认聚焦；无 3D 场景先行 |
| 启动中 | 锁定模式入口；超过 150ms 才显示遮罩与「正在进入{模式名}…」；退出仍可用 |
| 设置非法输入 | 越界收敛到最近边界并回写，提示变警告色；空/非数字恢复上次有效值；不阻断进入 |
| 模式初始化失败 | 模式区上方错误横幅（模式名 + 可读原因 + 重试 + 关闭提示），停留大厅，其他模式可选 |
| 音频缺失 | 黄色警告横幅，不阻断 |
| 外部模型预览 | 同窗替换主体：全宽路径输入（可粘贴）+ 加载模型 + 返回大厅；加载中禁用输入/按钮；错误内联且保留路径 |
| 模式内 Esc | 返回大厅并释放资源；横幅、旧路径、禁用态全部清空；设置保留；焦点回到刚退出的模式 |
| 大厅内 Esc | 优先级：编辑中撤销 → 有关闭横幅则关闭 → 预览则返回大厅 → 否则空操作；**永不退出程序** |
| 窗口缩放 / 最小化恢复 | 按断点实时重排，可见、可点击，不重叠、不隐藏；页脚「退出」始终可达 |

## 布局与视觉层级

完整断点/尺寸/焦点方案见 `ui-design.md` 第 1 节与第 3 节。要点：宽屏 ≥1080 双栏（左 58% 主入口 + 设置，右 42% 次级模式 + 错误横幅）；中屏 720–1079（含 800×600）单栏首屏完整；窄屏 <720 纵向堆叠、内容可滚动、页脚固定。主入口「开始训练」为唯一高视觉权重焦点；「退出」独立右置于固定页脚。按逻辑点布局，字体按 DPI 档预生成，最小目标 640×480。正常路径全中文，依赖 `research.md` R5 的内置中文字体；内置与系统 CJK 字体均不可用时才允许 ASCII 可读降级界面（异常兜底，非验收项）。

## 交互约束

- 连续快速确认：初始化开始前待启动模式以**最后确认**为准；初始化开始后入口锁定、后续输入忽略、不排队，只产生一次初始化（Edge Cases）。
- Esc 矩阵见 `ui-design.md` 4.3；预览加载中 Esc 忽略；任一模式 Esc 返回大厅而非退出。
- 键盘可达：Tab 顺序 主入口 → 外部模型预览 → 2D 输入演示 → Vulkan 清屏演示 → 灵敏度 → 音量 → 退出；焦点环 2px。
- 无音频设备：音量仍可调整，进入场景仅记录提示，不影响可用性。
- 返回大厅后再次进入同一模式：不保留上一局角色、靶板、机器人或模型状态；设置保留。
