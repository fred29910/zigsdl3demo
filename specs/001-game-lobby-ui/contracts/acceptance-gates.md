# Contract: 验收门禁与判定规则

本契约定义大厅功能是否被允许合入的唯一判定依据。任何一项失败都必须修复后重跑，不得以放宽门禁、跳过测试或改变玩法来迁就（FR-011、宪章 II/III）。实体字段见 [data-model.md](../data-model.md)，运行场景见 [quickstart.md](../quickstart.md)。

## 门禁清单

| # | 门禁 | 命令 | 覆盖范围 |
| --- | --- | --- | --- |
| G1 | 核心测试 | `zig build install test` | 基础设施、SDL 输入、场景句柄、变换、Render Queue、glTF 导入、物理 |
| G2 | ReleaseSafe 复测 | `zig build install test -Doptimize=ReleaseSafe` | 同上，带运行时安全检查 |
| G3 | 物理测试 | `zig build physics-test` | Jolt 碰撞、角色、射线与武器、路点、机器人行为 |
| G4 | 2D 模式独立测试 | `zig build test -Ddemo-2d=true` | 2D 演示独立构建与测试 |
| G5 | 清屏模式独立测试 | `zig build test -Dclear-only=true` | Vulkan 清屏独立构建与测试 |

**约束**：G4/G5 必须保持能独立构建与测试，不因引入大厅而依赖 Jolt、资产导入、ImGui 或音频集成。任何构建图改动都需复验这两条。

## 判定规则

- **通过**：G1–G5 全部退出码 0，且 [quickstart.md](../quickstart.md) 的 V1–V6 场景全部满足对应预期。
- **失败**：任一门禁失败 → 记录失败命令与错误摘要 → 修复后重跑全部门禁；不得修改 Zig 0.17.1 校验或降低验收标准。
- **玩法零回归**：README「手动验收」清单中原有条目继续通过；命中判定、武器参数、机器人行为、结算重开不得改变。
- **不变量**：物理步长 1/60 秒、每帧最多 6 步、相机胶囊脚点上方 1.6 米、最近碰撞射线；缓存语义（文件按规范绝对路径、内嵌按名称，默认训练场 `缓存命中 embedded:demo.glb`）；glTF 支持边界；HLSL/SPIR-V 同步。以上均不因大厅改动而变化。

## 用户可见行为契约

| 契约 | 必达行为 |
| --- | --- |
| 启动 | 首先呈现可交互的中文大厅；默认训练场仅在大厅明确确认后启动 |
| 模式切换 | 一次选择进入对应模式；模式内 Esc 返回大厅并释放资源；大厅内 Esc 不退出、不启动模式 |
| 退出 | 仅由大厅「退出」按钮或关闭窗口触发；无残留窗口与资源 |
| 外部模型 | 路径只在大厅进入的专门预览界面内以文本输入收集；无效路径/缺依赖时显示可读错误并可返回大厅 |
| 设置 | 视角灵敏度 0.5–2.0（默认 1.0，步长 0.05）、音量 0–100（默认 100）；实时显示；非法值收敛到边界+可读提示；会话内生效，不持久化 |
| 可见文本 | 全部中文，与 README 现有术语一致（FR-009） |
| 缩放 | 大厅响应窗口尺寸变化，所有控件可见可操作 |

## 失败与边界场景契约

- 模式初始化失败（图形/音频设备不可用、模型加载失败）：显示可读错误、停留大厅，可重试或改选，程序不退出。
- 无音频输出设备：音量仍可调整，进入场景仅记录提示，不影响可用性。
- 外部模型路径不存在、格式不支持或 `.bin`/纹理缺失：预览界面显示可读错误，允许返回大厅。
- 窗口缩放/最小化恢复：控件重新排布，不重叠、不隐藏、仍可点击。
- 连续快速点击多个模式入口：只进入最后确认的一个模式，不重复初始化或产生窗口冲突。
