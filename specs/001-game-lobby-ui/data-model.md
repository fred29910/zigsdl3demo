# Data Model: 游戏大厅界面

本功能不引入持久化存储或新的运行时数据文件。以下实体描述大厅会话、模式枚举与会话设置；其生命周期只存在于单次进程运行期间。

## 大厅会话 (LobbySession)

**来源**：spec.md 的 Key Entities「大厅会话」；生命周期从程序启动到退出。

| 字段 | 类型/取值 | 校验规则 |
| --- | --- | --- |
| 当前界面 | 枚举：大厅 / 默认训练场 / 外部模型预览 / 2D 输入演示 / Vulkan 清屏演示 | 启动时必须为大厅；同一时刻仅有一个当前界面 |
| 最后选择的模式 | 枚举：无 / 四个运行模式之一 | 仅在进入模式后更新；返回大厅时保留，供下次进入参考 |
| 会话设置 | 会话设置（见下） | 启动取默认值，不跨会话保存 |
| 当前提示 | 可为空的字符串 | 初始化失败/非法输入时必须给出可读中文提示；成功进入模式或输入合法后清空 |

**状态流转**：

```text
启动 → 大厅（可交互）
大厅 --选择模式--> 模式（初始化成功）
大厅 --选择外部模型预览--> 预览界面 --输入路径并确认--> 外部模型查看
大厅 --点击退出/关闭窗口--> 退出
任一非大厅模式 --按 Esc--> 大厅（释放该模式资源，清除当前提示）
任一非大厅模式 --初始化失败--> 大厅（保留可读提示，允许重试或改选）
```

**不变量**：任一时刻只有一个模式在运行；返回大厅后再次进入同一模式不得累积资源或保留上一局状态（FR-005、Edge Cases）。

## 运行模式 (RunMode)

**来源**：spec.md 的 Key Entities「运行模式」；共四项，与 README 现有运行模式一一对应，不新增第五种。

| 字段 | 说明 | 校验规则 |
| --- | --- | --- |
| 中文名称 | 「开始训练」「外部模型预览」「2D 输入演示」「Vulkan 清屏演示」 | 与 README 现有叫法一致（FR-009） |
| 入口标识 | 大厅中对应的选择项 | 一次选择即可进入对应模式（FR-003） |
| 可观察结果 | 进入后应呈现的画面或反馈 | 与既有验收记录一致；除进入/退出路径外玩法不变（FR-011） |
| 资源释放 | 返回大厅时必须释放该模式创建的资源 | 二次进入无状态残留（FR-005） |
| 失败处理 | 初始化失败时的可读提示与停留位置 | 必须停留大厅，程序不退出（FR-012） |

**外部模型预览子流程**：大厅只提供入口；模型路径在专门的预览界面内以文本输入方式填写或粘贴，确认后加载。路径无效、格式不支持或依赖的 `.bin`/纹理缺失时，预览界面显示可读错误并允许返回大厅（FR-004、Edge Cases）。

## 会话设置 (SessionSettings)

**来源**：spec.md Key Entities「会话设置」；Clarifications Session 2026-11-26 的具体范围与默认值。

| 字段 | 类型 | 默认值 | 允许范围 | 校验规则 |
| --- | --- | --- | --- | --- |
| 视角灵敏度 | 浮点数 | `1.0` | `0.5–2.0` | 步长 `0.05`；空/非数字/越界时收敛到允许范围边界并给出可读提示，不接受非法值进入场景 |
| 音量 | 整数 | `100` | `0–100` | 空/非数字/越界时收敛到允许范围边界并给出可读提示；无音频设备时仍可调整，进入场景仅记录提示 |

**会话语义**：设置仅在本会话内对随后进入的场景生效；程序重启时恢复默认值，不写入磁盘（FR-007、Assumptions）。

## 校验规则汇总（来自 FR）

- FR-001/FR-002：启动后必须先显示大厅；「开始训练」一次选择进入默认内嵌训练场。
- FR-003/FR-004：四个模式均可在大厅选择；外部模型路径仅由预览界面收集，大厅不收集。
- FR-005/FR-011：返回大厅后运行状态与资源不得影响下次进入；玩法与验收记录不变。
- FR-006/FR-007：设置实时显示当前数值、会话内生效、非法输入收敛并提示。
- FR-008：模式内 Esc 返回大厅；大厅内 Esc 不退出；退出仅由「退出」按钮或关闭窗口触发。
- FR-009/FR-010：所有可见文本中文；大厅状态响应窗口尺寸变化且控件可见可操作。
- FR-012：任一模式初始化失败显示可读错误并停留大厅，可重试或改选。
