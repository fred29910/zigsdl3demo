# Contract: 训练场输入契约

**Feature**: `004-training-mode-controls` | **Date**: 2026-11-26

本契约描述玩家可观察的输入行为，供实现与验收共同遵守。内部函数签名不属于本契约范围。

## 默认训练场

| 输入 | 可观察行为 | 关联需求 |
| --- | --- | --- |
| Tab | 捕获/释放鼠标；捕获后开始或继续训练，释放后暂停 | FR-004、FR-010 |
| 鼠标水平移动（捕获时） | 视线按位移与当前灵敏度成比例水平转向 | FR-001、FR-003 |
| 鼠标垂直移动（捕获时） | 视线抬升/下压，到上下限后停住且不翻转 | FR-002 |
| W / A / S / D | 相对当前视线的前、左、后、右平移；瞬间达到目标速度，松开即停 | FR-005、FR-014 |
| 两个相邻方向键同时按下 | 斜向速度不超过单向速度，方向为两者合力方向 | FR-006 |
| 两个相反方向键同时按下 | 相互抵消，角色静止 | 边界场景 |
| 左 Shift | 按住时移动速度提升，松开恢复 | FR-007 |
| 空格 | 着地时每次按下只起跳一次，按住不重复 | FR-008 |
| 顶住围墙斜向移动 | 沿墙滑动，不穿透、不卡死 | FR-009 |
| 窗口失焦 / 最小化 / 回合结束 | 清理按住状态，移动立即停止，视角不再响应鼠标 | FR-004、FR-010 |
| E（结算后） | 重开回合：视角、出生点、着地状态与按键状态恢复初始 | FR-011 |
| Esc | 从训练场返回大厅；大厅内不退出 | 既有行为，保持不变 |

## 大厅设置

| 项目 | 契约 |
| --- | --- |
| 视角灵敏度 | 0.5–2.0，默认 1.0；会话内有效、不持久化；进入训练场时生效，回合重开后仍保持一致 |
| 音量 | 0–100，默认 100；会话内有效、不持久化 |

## 构建与模式隔离

| 命令 | 契约 |
| --- | --- |
| `zig build run` | 启动内嵌训练场，先显示大厅 |
| `zig build run -Ddemo-2d=true` | 2D 输入演示独立于 Jolt、资产、ImGui、音频 |
| `zig build run -Dclear-only=true` | 清屏演示独立于 Jolt、资产、ImGui、音频 |
| `zig build install test` | 核心、输入、场景、资产、物理单元测试通过 |
| `zig build physics-test` | 角色移动、冲刺、沿墙、单次跳跃与取消通过 |

训练场控制改动不得使两个基础演示模式产生对上述依赖的需求（FR-012）。
